# IronRoot Consulting — website preview

Static one-page consulting site preview for IronRoot Consulting (Andrew Malby).

## What this is

- Preview only. Hosted via GitHub Pages when pushed.
- **Not** live on ironrootstrategy.com. No custom domain, CNAME, or DNS changes.
- Built from the One-Page Copy draft (Drive). Open `[ANDREW TO CONFIRM]` items stay marked on the page.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.
